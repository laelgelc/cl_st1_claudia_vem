# VEM Corpus

This repository contains Python scripts and data processing workflows for the VEM Corpus project. The project involves processing, cleaning, and analyzing text data.

## Project Structure

- **Python Scripts**: Scripts for various stages of data processing, such as PDF conversion, text extraction, and tokenization.
- **Data Folders**: Organized directories for intermediate and final outputs.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/jcollentine/vem-corpus.git
   ```
2. Navigate to the project directory:
   ```bash
   cd vem-corpus
   ```
3. Follow the scripts in numerical order for data processing.
